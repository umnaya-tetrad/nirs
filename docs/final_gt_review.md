# Решения по спорным GT-кейсам FERMAT

Все три кейса ниже добавлены в `dataset/final_gt.json`. FERMAT ставит им
`has_error=true` за порядок или повтор шагов, однако для итоговой разметки
применён согласованный критерий: неверный математический переход делает решение
`incorrect`, а недостатки подачи без математической ошибки остаются предупреждением.

| ID | Что видно в решении | Метка FERMAT | Предлагаемый GT-вердикт |
| --- | --- | --- | --- |
| `img_176_pert_4.3` | Даны два корректных способа перемножить дроби; во втором повторена часть промежуточных преобразований. Итог `1/2` верен. | Ошибка логического потока из-за повтора/перестановки. | `correct`, предупреждение о подаче. |
| `img_151_pert_4.3` | В промежуточном шаге вместо требуемого умножения записан минус; итоговый ответ не исправляет неверный переход. | Ошибка логического потока. | `incorrect`, первый ошибочный шаг `s1`. |
| `img_92_pert_4.3` | Для 40 минут правильно получены угол `240^\circ = 4\pi/3` и путь `6.28` см; сначала записан расчёт пути, затем его обоснование. | Ошибка логического потока из-за перестановки шагов. | `correct`, предупреждение о подаче. |

Разметка final-набора завершена: 80 уникальных ID из manifest покрыты GT.
