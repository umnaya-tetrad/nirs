# Фото smoke-набора моделей

Здесь лежат 10 публичных изображений из `Karifannaa/EGE_Math_Solutions_Assessment_Benchmark` для локального интерфейса сравнения моделей: пять работ с максимальным баллом 2 и пять с баллом 1, только по заданиям 13 и 15. Все записи одностраничные (`parts_count=1`) и взяты исключительно из поля `images_without_answer`, то есть это фото без готового ответа.

`manifest.json` фиксирует строку датасета и имя файла. Повторно скачать набор можно командой `python app/download_benchmark_cases.py` из окружения бэкенда. Лицензия датасета обозначена автором как `other`; используем эти файлы только для исследования и внутренней демонстрации. Их нельзя выдавать за пользовательские фото или включать в публичные/маркетинговые материалы без разрешения правообладателя.
